================================================================================
                        LAMBDA SYNTAX AT A GLANCE
================================================================================

No parameters:
  () -> expression

Single parameter:
  x -> expression

Multiple parameters:
  (a, b) -> expression

Block body:
  (a, b) -> {
      int result = a + b;
      return result;
  }

================================================================================
                        TIPS & TRICKS
================================================================================

TIP 1: Keep lambdas short
  BAD:   x -> {int y = x*2; int z = y*y; return z;}
  GOOD:  x -> x * x * 4

TIP 2: Use method references
  BAD:   list.forEach(item -> System.out.println(item))
  GOOD:  list.forEach(System.out::println)

TIP 3: Use appropriate interface
  BAD:   Function<Integer, Void> for side effects
  GOOD:  Consumer<Integer> for side effects

TIP 4: Chain operations
  list.stream()
    .filter(x -> x > 5)
    .map(x -> x * 2)
    .forEach(System.out::println)

TIP 5: Compose functions
  Function<Integer, Integer> f = add5.andThen(mult2)

TIP 6: Combine predicates
  Predicate<Integer> p = gt5.and(lt10)

TIP 7: Use type inference
  (x, y) -> x + y  (types inferred)

TIP 8: Avoid side effects
  No modifications of captured variables

================================================================================
                        COMMON MISTAKES
================================================================================

MISTAKE 1: Modifying captured variables
  ❌ BAD:  int x = 5; x++; lambda use x (x is not effectively final)
  ✓ GOOD: final int x = 5; or int x = 5; (don't modify)

MISTAKE 2: Forgetting return
  ❌ BAD:  x -> {y = x * 2}
  ✓ GOOD: x -> {y = x * 2; return y;}

MISTAKE 3: Using wrong interface
  ❌ BAD:  Function<String, Void> for printing
  ✓ GOOD: Consumer<String> for printing

MISTAKE 4: Complex logic in lambda
  ❌ BAD:  list.map(x -> {method1(); method2(); return transform(x);})
  ✓ GOOD: list.map(this::processItem)

MISTAKE 5: Not using method references
  ❌ BAD:  list.forEach(item -> System.out.println(item))
  ✓ GOOD: list.forEach(System.out::println)
