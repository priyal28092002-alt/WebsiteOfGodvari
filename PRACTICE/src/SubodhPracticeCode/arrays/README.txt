ARRAY TECHNIQUES - TCS NQT PRIME CODING ROUND
==============================================

Created comprehensive array problem-solving programs in:
com.example.arrays package (Java_Programming project)

FILES CREATED:
--------------

1. SlidingWindowTechnique.java
   - Fixed window (max/min sum of k consecutive)
   - Variable window (smallest/longest subarray with condition)
   - Core concept for contiguous subarray problems
   - Time: O(n), Space: O(1)

2. TwoPointerTechnique.java
   - Two sum in sorted array
   - Remove duplicates
   - Dutch National Flag (sort 0s, 1s, 2s)
   - Container with most water
   - Core concept for sorted array and partition problems
   - Time: O(n) or O(n²), Space: O(1)

3. PrefixSumTechnique.java
   - Range sum queries
   - Equilibrium index
   - Subarray sum equals K
   - Maximum subarray sum (Kadane's algorithm)
   - Product except self
   - Core concept for range queries and subarray sums
   - Time: O(n), Space: O(n) or O(1)

4. ArrayRotationTechnique.java
   - Rotate left/right by k positions (reversal algorithm)
   - Search in rotated sorted array
   - Maximum circular subarray sum
   - Core concept for circular array problems
   - Time: O(n), Space: O(1)

5. FrequencyCountingTechnique.java
   - Count frequencies using HashMap
   - Find duplicates
   - First non-repeating element
   - Majority element (Moore's Voting Algorithm)
   - Top K frequent elements
   - Core concept for counting and frequency analysis
   - Time: O(n), Space: O(n)

6. SortingBasedTechnique.java
   - Three sum problem
   - Merge overlapping intervals
   - Meeting rooms / minimum platforms
   - Closest pair to target sum
   - Core concept for interval and pair problems
   - Time: O(n log n), Space: O(1) or O(n)

7. InPlaceManipulation.java
   - Move zeros to end
   - Segregate positive/negative
   - Find duplicates using sign marking
   - Cyclic sort for missing numbers
   - Rearrange by index
   - Core concept for space-optimized solutions
   - Time: O(n), Space: O(1)

8. StackBasedTechnique.java
   - Next Greater Element (NGE)
   - Stock Span Problem
   - Largest Rectangle in Histogram
   - Rain Water Trapping
   - Celebrity Problem
   - Core concept for monotonic sequences
   - Time: O(n), Space: O(n)

9. MathematicalTechnique.java
   - Find missing number (sum/XOR methods)
   - Single number (XOR property)
   - Two unique numbers (bit manipulation)
   - Generate all subsets (bit masking)
   - GCD/LCM of array
   - Count set bits
   - Core concept for formula-based and bitwise solutions
   - Time: O(n), Space: O(1)

10. TechniqueSelectionGuide.java
    - Decision tree for selecting right technique
    - Pattern recognition guide
    - Problem-to-technique mapping
    - Quick reference for interviews
