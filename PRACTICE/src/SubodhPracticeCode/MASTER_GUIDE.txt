ARRAY TECHNIQUES (9 Core Techniques)
===============================================================================

Location: com.example.arrays

1. SlidingWindowTechnique.java
   → Max/min sum of k consecutive elements
   → Smallest/longest subarray with condition
   → Use for: Consecutive elements, contiguous subarrays
   
2. TwoPointerTechnique.java
   → Two sum, remove duplicates, partition
   → Container with most water, Dutch National Flag
   → Use for: Sorted arrays, pairs, comparing ends
   
3. PrefixSumTechnique.java
   → Range sum queries, equilibrium index
   → Kadane's algorithm, product except self
   → Use for: Multiple queries, subarray sums
   
4. ArrayRotationTechnique.java
   → Rotate left/right, search in rotated sorted
   → Maximum circular subarray sum
   → Use for: Rotation, circular patterns
   
5. FrequencyCountingTechnique.java
   → Find duplicates, majority element
   → Top K frequent, subarray with sum 0
   → Use for: Counting, frequency analysis
   
6. SortingBasedTechnique.java
   → Three sum, merge intervals, meeting rooms
   → Minimum platforms, closest pairs
   → Use for: Intervals, pairs after sorting
   
7. InPlaceManipulation.java
   → Move zeros, segregate, cyclic sort
   → Find duplicates without extra space
   → Use for: O(1) space constraint
   
8. StackBasedTechnique.java
   → Next Greater Element, Stock Span
   → Largest Rectangle, Rain Water Trapping
   → Use for: Monotonic sequences, histogram
   
9. MathematicalTechnique.java
   → Find missing (XOR, sum formula)
   → Bit manipulation, GCD/LCM, subsets
   → Use for: Formula-based, bitwise operations

10. TechniqueSelectionGuide.java
    → Decision tree and quick reference

HOW TO USE THIS RESOURCE
===============================================================================

STEP 1: Understand the Pattern
   → Read TechniqueSelectionGuide files first (Array & String)
   → Learn to recognize problem patterns from keywords
   
STEP 2: Master One Technique at a Time
   → Pick one technique file
   → Run the program and study the output
   → Understand WHY the technique works
   → Code along and modify examples
   
STEP 3: Practice Variations
   → Each technique file has multiple problems
   → Solve similar problems on your own
   → Don't just memorize - understand the concept
   
STEP 4: Pattern Recognition
   → Practice identifying technique from problem statement
   → Look for keywords: "consecutive", "subarray", "palindrome", etc.
   → Use decision trees in guide files
   
STEP 5: Mixed Practice
   → Once comfortable with all techniques
   → Practice random problems
   → Time yourself
   
STEP 6: Interview Simulation
   → Solve problems without looking at reference
   → Explain your approach out loud
   → Optimize after getting working solution

===============================================================================
COMPLEXITY TARGETS FOR INTERVIEWS
===============================================================================

OPTIMAL TIME COMPLEXITIES:
O(n)     - Single pass (most array/string traversals)
O(n log n) - When sorting is needed
O(n²)    - Nested loops (acceptable for small n)
O(2^n)   - Exponential (only for small inputs)

SPACE OPTIMIZATION:
O(1)     - In-place (preferred when possible)
O(n)     - Extra array/map (acceptable)
O(n²)    - DP table (for specific problems)

===============================================================================
COMMON MISTAKES TO AVOID
===============================================================================

1. Not checking edge cases (null, empty, single element)
2. Off-by-one errors in loops
3. Not handling string immutability (use StringBuilder)
4. Forgetting to handle integer overflow
5. Not optimizing from brute force
6. Assuming sorted when not specified
7. Confusing substring vs subsequence
8. Not considering negative numbers in arrays

===============================================================================
KEY FORMULAS & PROPERTIES
===============================================================================

ARRAYS:
- Sum 1 to n: n*(n+1)/2
- Subarray count: n*(n+1)/2
- XOR property: a^a = 0, a^0 = a
- Two sum in sorted: O(n) with two pointers

STRINGS:
- Substrings: n*(n+1)/2
- Subsequences: 2^n
- ASCII: 'A'=65, 'a'=97, difference=32
- Anagram: Same frequency of all characters
