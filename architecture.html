🔌 API Endpoints (via Gateway :8087)
👤 Auth & Users
POST/auth/registerRegister user
POST/auth/loginLogin → JWT
GET/usersAll users (admin)
GET/users/{id}Get user
PUT/users/{id}Update user
📦 Products
GET/productsList products (paginated)
GET/products/{id}Get product
POST/productsAdd product (admin)
PUT/products/{id}Update product
DEL/products/{id}Delete product
GET/products/categoriesAll categories
POST/products/categoriesAdd category
🧾 Orders
POST/ordersPlace order
GET/ordersAll orders (admin)
GET/orders/user/{userId}My orders
GET/orders/{id}Get order
PUT/orders/{id}/statusUpdate status
GET/orders/dashboard/statsDashboard stats
🏭 Inventory
GET/inventoryAll stock
GET/inventory/product/{id}Stock by product
GET/inventory/low-stockLow stock alerts
POST/inventory/updateAdd / deduct stock
GET/inventory/transactions/{id}Stock history
📋 Quotations
POST/quotationsSubmit RFQ
GET/quotationsAll quotations (admin)
GET/quotations/user/{id}My quotations
GET/quotations/{id}Get quotation
PUT/quotations/{id}/statusApprove / Reject
💰 Billing
POST/billing/invoicesGenerate invoice
GET/billing/invoicesAll invoices (admin)
GET/billing/invoices/user/{id}My invoices
GET/billing/invoices/order/{id}Invoice by order
PUT/billing/invoices/{id}/payMark as paid
🔗 Inter-Service Calls (all via API Gateway)
🧾 Order Service calls
On order CREATE → POST /inventory/update (OUT) → Inventory Service
On order CONFIRMED → POST /billing/invoices → Billing Service
📋 Quotation Service calls
On quotation APPROVED → POST /orders → Order Service (auto-creates order)
📦 Product Service
No outbound calls · serves product catalog · Redis cached
🏭 Inventory Service
No outbound calls · receives stock updates · Redis cached
💰 Billing Service
No outbound calls · receives invoice requests · stores in MySQL
👤 User Service
No outbound calls · auth gateway · JWT generation & validation
